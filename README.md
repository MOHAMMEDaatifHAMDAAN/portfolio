## 🚀 How to View Locally

Simply open `index.html` in any browser:

```powershell
# Method 1: Open index.html directly
Start-Process "C:\Users\aatif\.gemini\antigravity\scratch\aatif-portfolio\index.html"
```

Or run a local HTTP development server:

```powershell
# Method 2: Python HTTP Server
cd C:\Users\aatif\.gemini\antigravity\scratch\aatif-portfolio
python -m http.server 3000
```
Then open `http://localhost:3000` in your browser.
